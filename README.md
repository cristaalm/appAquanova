# AquaNova-Hidroponia

## Instalación Básica

### Requerimientos Previos

Antes de comenzar con la instalación, asegúrate de tener los siguientes requerimientos previos:

- Python 3.6 o superior
- Git
- Acceso a internet

Para verificar la versión de Python instalada, ejecuta:

```bash
python --version
```

o

```bash
python3 --version
```

Para verificar la instalación de Git, ejecuta:

```bash
git --version
```

## Instalación

Para configurar el proyecto AquaNova-Hidroponia, sigue los siguientes pasos:

1. Clona el repositorio ejecutando el siguiente comando:

   ```bash
   git clone https://github.com/cristaalm/AquaNova-Hidroponia.git
   ```

2. Instala las dependencias necesarias desde el archivo `requirements.txt` utilizando el siguiente comando:

   - En Windows:

   ```bash
   pip install -r requirements.txt
   ```

   - En Linux:

   ```bash
   pip3 install -r requirements.txt
   ```

## Ejecución del proyecto

3. Para ejecutar el proyecto, utiliza uno de los siguientes comandos según tu sistema operativo:

   - En Windows:

   ```bash
   python main.py
   ```

   - En Linux:

   ```bash
   python3 main.py
   ```
